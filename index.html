Запуск сайту для будівельного магазину

E-commerce платформа для офлайн будівельних магазинів.

Каталог товарів
  • Збирала та аналізувала бізнес-вимоги щодо перенесення офлайн-асортименту в інтернет-магазин.
  • Описувала структуру багаторівневого каталогу товарів, правила категоризації та атрибути для різних груп будівельної продукції.
  • Формувала вимоги до пошуку, фільтрації, відображення характеристик товарів, а також синхронізації каталогу, цін і залишків з обліковою системою.
  • Розробляла Use Cases, функціональні вимоги та Acceptance Criteria для функціоналу каталогу.

Результат: реалізовано можливість самостійного керування каталогом контент-менеджером без залучення команди розробки.

Особистий кабінет
  • Збирала та аналізувала вимоги до функціоналу особистого кабінету користувача.
  • Описувала бізнес-процеси реєстрації, авторизації, перегляду історії замовлень, повторного замовлення та керування адресами доставки.
  • Моделювала бізнес-процеси за допомогою Flow Diagram та розробляла Use Cases для ключових сценаріїв.
  • Узгоджувала логіку відображення статусів замовлень між сайтом та внутрішньою системою обробки замовлень.

Результат: користувачі отримали можливість самостійно відстежувати статус замовлень без звернення до служби підтримки.

Список бажань та порівняння товарів
  • Аналізувала бізнес-вимоги та описувала логіку роботи списку бажань і порівняння товарів.
  • Розробляла функціональні вимоги до збереження обраних товарів для авторизованих і неавторизованих користувачів.
  • Описувала логіку синхронізації списків після авторизації та правила порівняння товарів за технічними характеристиками в межах однієї категорії.
  • Готувала Use Cases, Acceptance Criteria та функціональні специфікації для реалізації функціоналу.

Результат: менше звернень у підтримку з питанням «що краще обрати».

Онлайн-система оформлення повернення товарів

Інтернет-магазин товарів для саду та городу.

Основні задачі
  • Збирала та аналізувала бізнес-вимоги щодо процесу повернення товарів.
  • Моделювала процес повернення товарів за допомогою Flow Diagram.
  • Описувала сценарії повернення товару через відділення магазину або службу доставки (Нова пошта).
  • Розробляла функціональні вимоги до форми оформлення повернення (дані замовлення, причина повернення, спосіб повернення, контактні дані, реквізити для відшкодування).
  • Розробляла Use Cases, функціональні специфікації та критерії приймання для реалізації функціоналу.
  • Визначала бізнес-правила, правила валідації форми та логіку обробки заявок.
  • Описувала процес обробки заявки: від створення клієнтом до перевірки, погодження та завершення повернення співробітником компанії.
  • Узгоджувала вимоги із замовником, дизайнером та командою розробки.

Результат: автоматизовано процес оформлення повернення товарів через сайт, що дозволило клієнтам дистанційно подавати заявку на повернення та обирати спосіб відправлення товару (через магазин або Нову пошту).
